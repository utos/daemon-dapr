# Evaluation conformance corpus

Vendored from [`utos/api`](https://github.com/utos/api) `conformance/evaluation/` at **v0.0.16**,
by hand — the daemon has no release pipeline that vendors the spec the way the SDK repos do.
`EvaluationConformanceTests` runs every case here against `JintTemplateEngine`.

To update: copy `api/conformance/evaluation/*.json` over this directory and bump the tag above.
The README of the source directory describes the case format.
